# SAFE

SAFE (Statistical Analysis of Structure Factors and Normalised E Values)

SAFE provides a modern workflow for preparing, running and analysing
INSTAT calculations for both small-molecule and macromolecular
crystallography.

Current features:

- CIF-HKL support
- SHELX support
- MTZ support
- Protein, DNA and RNA composition handling
- Automated STIN preparation
- INSTAT execution
- INSTAT output analysis

Future developments:

- Lévy analysis
- Alternative scaling methods
- Extended space-group statistics
- Additional macromolecular workflows

## Installation

pip install -e .

## Command line tools

safe-run-instat
safe-analyse-instat
safe-prepare-sm
safe-prepare-mx
